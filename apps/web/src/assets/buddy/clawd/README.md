# Clawd

Frame-by-frame pixel-art clips drawn for T3 Code, one per buddy state. The
proportions follow the Clawd anatomy reference in
[xixicc186/clawd-emotes-skill](https://github.com/xixicc186/clawd-emotes-skill)
(MIT), including the canonical `#DE886D` shell, and the frames are encoded as
VP9 with alpha at 480×480, 24 fps.

| File            | Motion                                   |
| --------------- | ---------------------------------------- |
| `idle.webm`     | Breathing bob, blink, small eye darts    |
| `thinking.webm` | Looks up while a thought bubble fills in |
| `working.webm`  | Types at a keyboard, hands alternating   |
| `waiting.webm`  | Scans around, taps a foot, "…" bubble    |
| `success.webm`  | Crouch, jump, sparkles, land             |
| `error.webm`    | Slumps under a rain cloud, sweat drop    |
| `angry.webm`    | Shakes, red cheeks, gritted teeth, steam |

Clawd is Anthropic's Claude Code mascot, so the character belongs to Anthropic.
Treat this art as fan work rather than a T3 Code mark.
